# PixelForge Client

Lunar-style Fabric utility client for **Minecraft 1.21.11**.

**No cheats.** Clean HUD, visuals, utilities, performance tools, PvP trainer hooks and profile system.

## Features
- Custom transparent main menu
- Lunar-style ClickGUI (Right Shift) — short, classy, transparent panels
- Profile system with prebuilt profiles: **PvP · Survival · Minigames · UHC · SMP · Default**
- Full HUD suite (FPS, CPS, Coords, Armor, Potions, Keystrokes, etc.)
- Custom crosshair styles
- Fullbright, NoHurtCam, Zoom, AutoTool, AutoEat, ToggleSprint and more
- Config save/load per module

## Requirements
- Minecraft **1.21.11**
- Fabric Loader ≥ **0.19.3**
- Fabric API **0.141.6+1.21.11**
- Java **21**

## Build
```bash
./gradlew build
```
Jar output: `build/libs/pixelforge-1.0.0.jar`

## Controls
- **Right Shift** — Open / close ClickGUI
- Click profile name in ClickGUI to cycle prebuilt profiles
